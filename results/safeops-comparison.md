# planproof and the safe-ops gate, side by side

Generated by `make safeops-compare` (PRD E-20); don't edit by hand. Kernel 0.2.0; safe-ops-agent-k8s commit `4d13940`, gate policy `sha256:af48c536addd`.

safe-ops' side is its own controller code and `gate.rego`, unchanged; only its server-side dry run is simulated (the patch applied locally, the dry run reported as accepted). Each `scale` and `rollout-restart` step is one ChangeRequest, reviewed after the earlier ones have finished; waits are dropped; a plan with any other operation is **not expressible** as ChangeRequests. Outcomes: safe-ops **Deny** (no approval can override), **Escalate** (a person must approve), **Allow**; planproof **Refuted** or **Unknown** (cannot be approved), **Proved** (a person checks the goal; *approval* marks the plans the policy sends to a person). See the [PRD](../docs/prd/areas/e-agent-and-evals.md#head-to-head-with-the-safe-ops-gate-e-20) for how the policy was translated.
